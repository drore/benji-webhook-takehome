# Specifications

This directory holds the developing design and implementation specification for the Benji senior software engineer take-home. Update the working spec as decisions are made and implementation evidence changes.

- [Webhook notification system](spec-design-webhook-notifications.md) — requirements, proposed architecture, dashboard design, demo, acceptance criteria, and open decisions.
- [SDD-TDD iteration plan](spec-process-sdd-tdd-iterations.md) — whole-system and feature-level slices, acceptance gates, and test cadence.
- [Security and scalability boundaries](spec-architecture-security-and-scale.md) — local safeguards, production gaps, and reproducible local tests.

The [assignment](https://even-foxglove-53c.notion.site/Sr-Software-Engineer-380b9f151bae81218487d84c42741d17) is the source for requested outcomes. The working spec labels interpretations and proposals separately from those outcomes.
